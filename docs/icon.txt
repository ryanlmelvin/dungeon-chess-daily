The installed app and browser icons share the same knight-and-dungeon artwork.
The maskable variant adds padding to keep the knight inside circular crops.
Manifest icon URLs carry a version so installed apps can detect the new artwork.
The high-resolution source stays outside public/ so it is not downloaded offline.

To export the shipped sizes on macOS, run from the repository root:

sips -z 512 512 assets/icon-source.png --out public/icons/icon-512.png
sips -z 192 192 assets/icon-source.png --out public/icons/icon-192.png
sips -z 180 180 assets/icon-source.png --out public/icons/apple-touch-icon.png
sips -z 410 410 assets/icon-source.png --out /tmp/dungeon-knight-maskable.png
sips -p 512 512 --padColor 100f14 /tmp/dungeon-knight-maskable.png --out public/icons/maskable-512.png
